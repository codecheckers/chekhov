# Chekhov logo / icon

Source files for the bot's avatar and icon.

## Brand facts

- CODECHECK green: `#008033`
- White: `#FFFFFF`
- The parent logo is a green rounded rectangle with the white "CODE CHECK"
  wordmark and a large hand-drawn-style white tick. **Only the tick survives at
  avatar size** — the wordmark must be dropped for the bot icon.
- Reference artwork: `codecheckers.github.io/logo/` and `img/codecheck_logo.svg`

## Files

| File | Purpose |
|---|---|
| `PROMPT.md` | Generation prompts + acceptance checklist for the avatar |
| `chekhov_avatar.svg` | (TODO) source artwork, redrawn as vector |
| `chekhov_avatar.png` | (TODO) 400x400 export, used as the GitHub avatar |

## Requirements

- Square, exports cleanly at 400x400 and still readable at 24 px
- Two colours only, exactly `#008033` and `#FFFFFF`
- No text of any kind
- Recognisable next to the main CODECHECK logo without competing with it
